## Overview

Running a batch of jobs across a few machines usually means babysitting SSH sessions and losing track of what ran where. **nextask** is a small distributed task queue that keeps the bookkeeping: you enqueue commands from one place, workers claim them atomically, and heartbeats catch the ones that stall. Each task can carry a git snapshot of the exact tree it ran from, so any run stays reproducible, which makes it a natural fit for ML sweeps and agent-driven workflows.

</HighlightedSection>

## How it works

    <NextaskDiagram slot="figure" />
    <Fragment slot="caption">
      One task through its lifecycle: (1) the CLI enqueues it into the
      Postgres-backed queue, (2) `--snapshot` pushes the working tree to the
      git remote, (3) a matching worker claims it atomically, and (4) logs
      stream back to the attached client live. Green dots are worker
      heartbeats; the status chip moves from pending to running to completed.

## Agent-ready

nextask is agent ready by design. Install the [skills](https://github.com/TolgaOk/nextask/tree/main/skills) to let agents set up services, deploy workers, and manage tasks:

```sh
npx skills add https://github.com/TolgaOk/nextask/skills
```

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/TolgaOk/nextask/main/install | bash
```
